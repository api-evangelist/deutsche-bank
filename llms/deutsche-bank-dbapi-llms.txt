# Deutsche Bank - dbAPI Program

> Deutsche Bank's developer programme (dbAPI) publishes 36 first-party OpenAPI 3.0.x contracts covering 195 operations across banking, cards, payments, investments, lending, onboarding and reference data. Every contract below was retrieved from Deutsche Bank's own public swagger catalogue at https://simulator-api.db.com/gw/public/dbapi/swaggers/v1/ and is stored verbatim in this repository. The same operations serve three tenants - Deutsche Bank (api.db.com), norisbank (api.norisbank.de) and Postbank (api.postbank.de).

Generated by the API Evangelist enrichment pipeline on 2026-09-06 from this repository's own artifacts. This is NOT a Deutsche Bank publication; Deutsche Bank's own llms.txt is at https://www.db.com/llms.txt and is stored beside this file.

## Access

- Sandbox: https://simulator-api.db.com/gw/dbapi - free, self-service, persona-based test users
- Production: https://api.db.com/gw/dbapi (also api.norisbank.de, api.postbank.de) - requires an approved go-live request
- Auth: OAuth 2.0 / OIDC. Issuer https://simulator-api.db.com/gw/oidc/ - authorization code (+PKCE S256), client credentials, refresh token, device code, token exchange; mTLS client auth supported
- Scopes: 42 published scopes across 8 groups - see scopes/deutsche-bank-scopes.yml
- Every operation requires a Correlation-Id request header
- 33 of 128 write operations accept an idempotency-id (uuid) header; a collision returns 409 / code 6506
- No rate limits, no 429 and no Retry-After are published anywhere in the estate
- Errors are a proprietary { code, message, messageId } JSON envelope, NOT RFC 9457. 190 numeric codes are catalogued in errors/deutsche-bank-error-codes.yml
